# 如何制定个人预算

个人预算的核心不是把钱卡得很死，而是给每一笔收入安排明确用途。

先记录固定支出，再预留储蓄和弹性消费，最后根据实际情况调整比例。这样做的目标，是让预算长期可执行，而不是只在第一个月有效。

## 一个更容易坚持的顺序

1. 先列出房租、交通、餐饮、通信等固定支出。
2. 再把储蓄和应急金放进月度预算。
3. 最后给娱乐、购物和临时开销留出弹性空间。

预算不是为了制造压力，而是为了让每次消费都有判断依据。
