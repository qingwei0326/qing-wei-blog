# Claude / ChatGPT 海外订阅怎么省：我用苹果渠道把月费压到 ¥80

> **这篇受众有偏**：不是写给"大学生通用算账"的，是写给已经在用 Claude / Codex 做开发或重度内容工作的人。日常没用 AI 工具的话，这一篇可以跳过。

（下面我把 ChatGPT 都叫 **Codex**，发音顺一点。）

> 价格、可用地区、支付方式和服务条款都会变化。下面的数字与步骤是我在 2026 年 5 月的个人记录，不代表当前或所有账号都适用；操作前请以产品官方页面、Apple 当前规则和当地法律为准。

这篇按速查表写：先对比三条路，再给我走的那条路的账和步骤，最后是风险。

## 三条路对比

在我 2026 年 5 月尝试时，Claude / ChatGPT 的国内支付路径不稳定，国内卡没有顺利完成付款。当前是否支持、哪些地区可用，要以产品官方页面为准。绕过去有三条路：

| 路径 | 门槛 | 风险 / 缺点 |
|---|---|---|
| 官网信用卡 | 要海外信用卡 + 海外地址 + 干净 IP | 门槛高、风控严 |
| **苹果 App Store**（我走的） | 海外区 Apple ID + 海外区 iTunes 礼品卡 | 走正规消费链路，封号风险最低；但账号、礼品卡、IP 都要维护 |
| 第三方中转站 | 用别人代充的 API | 便宜，但稳定性 / 数据安全都打折 |

## 算账：到底省多少

| 渠道 | 月费 |
|---|---|
| 美区原价（Claude Pro / ChatGPT Plus，当时记录） | $20 ≈ **¥145** |
| 苹果尼区充值 → Claude | **¥86** |
| 苹果土区充值 → Codex | **¥76-80** |

按我当时记录的两个价格计算，**每月差额约 ¥125，一年约 ¥1500**；汇率、税费、礼品卡溢价和产品价格变化后，结果会不同。

> **先说结论：** 我走的是海外区 Apple ID + iTunes 礼品卡 + App Store 内购。优点是链路正规、比美区便宜；缺点是账号、礼品卡、IP 都要维护，价格和风控也会变。

## 风险与规则

### 网络

在我当时的使用环境里，这两项服务都需要稳定的网络连接；具体可用性和限制以服务条款及官方说明为准。我自己摸出来的几条规则：

| 规则 | 说明 |
|---|---|
| Claude 风控特别严 | 烂大街的"万人骑"机场被一批标记后大概率出问题；Codex 风控稍松，但也别用太便宜的 |
| 不要乱换 IP | 刚才美区、一小时后日本，这种轨迹很容易触发风控 |
| 一个号绑一个 IP 段 | 哪怕慢点也比换来换去稳 |
| 设备越少越好 | 我 Claude 只用电脑端（含 Claude Code），其他设备一律不登 |

至于如何在遵守服务条款的前提下减少登录和支付失败，下一篇专门讲，这篇先解决"账号 + 充值"。

### 我没敢用的功能：cowork

Claude 有个叫"**cowork**"的协作功能，但我看到过有人开了之后被封号，所以我没敢用。国内能不能用，欢迎了解的朋友评论区聊一下。
