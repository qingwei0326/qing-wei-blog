## 为什么不直接订美区

Claude / ChatGPT 在国内**都没有官方支付路径**——你拿张国内卡，刷不了。

绕过去有几条路：

- **官网信用卡**：要海外信用卡 + 海外地址 + 干净 IP，门槛高、风控严
- **苹果 App Store**：用海外区 Apple ID + 海外区 iTunes 礼品卡，**走的是正规消费链路**，封号风险最低
- **第三方中转站**：用别人代充的 API，便宜但稳定性 / 数据安全都打折

我走的是 **App Store 路径**，下面是完整流程。

## 第 1 步：苹果 ID

**前置**：必须有一台苹果设备（iPhone / iPad / Mac 都行），国内卡国内手机号也行，**不需要苹果生态全套**。

## 第 3 步：充值 + 订阅

1. 打开 App Store → 搜索 "**礼品卡**" / "兑换"

4. 自动续订，账户余额够就一直续

## 网络这块：先讲规则，下篇讲怎么搭

直白说：**这两家都需要稳定的海外 IP**。

我自己摸出来的几条规则：

- **Claude 风控特别严**——烂大街的"万人骑"机场被一批标记后大概率出问题；Codex 风控稍松，但也别用太便宜的
- **不要乱换 IP**：刚才美区、一小时后日本——这种轨迹很容易触发风控
- **一个号绑一个 IP 段**：哪怕慢点也比换来换去稳
- **设备越少越好**：我 Claude 只用电脑端（含 Claude Code），其他设备一律不登

至于**具体怎么搭一个不被风控的链路**——下一篇专门讲，这篇先解决"账号 + 充值"。

## 中转站 freemodel：另一条路 ⚠️ 利益相关

如果不想搞苹果 ID + 礼品卡这一套，**第三方中转站**是另一条路。

我自己用的是 **freemodel.dev**：
- 新用户首月送 **$300** 额度
- 之后按使用量扣（约 $66.67 / 周、5 小时 $10）
- **缺点**：不能用 image 相关功能

我**只把闲杂数据放在中转站上跑**——核心活儿还是走苹果订阅的官方账号。中转站最大的问题是**水量不稳 + 数据安全**：

> 我见过有些中转站成本几十块、被封前一两天就能赚 200+ 刀——暴利行业，良心商家也容易因为利益变形。

中转站可以用，但**别把核心数据放上面**。
