# 识别消费陷阱

很多超支并不是因为商品本身贵，而是因为买单前的判断被放松了。

常见陷阱包括限时优惠、凑单满减、情绪消费和重复购买。先判断需求，再看价格，最后再决定是否下单，通常会少很多后悔。

## 下单前的三次确认

1. 这件东西是否解决了真实问题？
2. 如果没有折扣，我还会买吗？
3. 未来一个月内，它会被稳定使用吗？

把消费决策拉回到需求本身，才是减少浪费最有效的办法。
