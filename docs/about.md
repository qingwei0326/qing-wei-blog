# 关于我

我是青微，一个喜欢折腾技术、也喜欢琢磨怎么把日子过得更明白的人。

日常生活里维护着几个小服务跑在自己的服务器上，用 WSL + PM2 管理部署，习惯拿自动化省掉重复劳动。工作之外会看 A 股和美股，定期整理复盘笔记——虽然水平还在长进，但保持关注本身就是一种训练。

## 这个博客

这里记录的主要是我踩过的坑和试出来的办法。怎么省钱但不压榨生活质量、怎么用信息差和工具组合把体验提上去——写下来一半是为了自己复盘，一半是觉得或许对别人也有点用。

目前文章偏生活优化和理财，技术相关的内容后续会慢慢补上——折腾过程中有意思的东西攒了不少。
